# Writing Task 1

Eighteen Task 1 prompts covering every visual type: line graph, bar chart, pie charts, table, process (man-made and natural/system), maps (past→present and planned) and mixed charts.

**Each folder contains**
| File | Purpose |
|---|---|
| `prompt.md` | The task, with the data as a table or ASCII diagram. |
| `data.json` | Machine-readable chart spec (`line`, `bar`, `pie`, `table`, `process`, `map`, `mixed`) so an app can draw the real chart. |
| `model_answer.md` | Band 8–9 model, then (after `---`) examiner notes, structure and useful language. |
| `meta.json` | Title, level, chart type. |

**The 4-paragraph formula:** Introduction (paraphrase) → **Overview** (main trends, no numbers) → Body 1 → Body 2. **20 minutes, 150+ words.**
