# Free official resources and further practice

All practice material in this repo is **original**. It is written to match the official IELTS format, question types and band descriptors, but it does not copy any copyrighted test. Use the official sources below for authentic past-paper-style practice alongside it.

## Paid but authoritative
- **Cambridge IELTS Academic 1–19** (Cambridge University Press): authentic past papers with audio and answer keys. The best mock-test source.
- **The Official Cambridge Guide to IELTS**: strategies plus 8 practice tests.

## Daily input (free, academic-style English)
| Skill | Source | Why |
|---|---|---|
| Reading | BBC Future, The Conversation, The Guardian (Science / Environment), National Geographic | Similar topics and register to Academic Reading |
| Listening | BBC Radio 4 *In Our Time*, BBC *6 Minute English*, TED Talks, university lectures on YouTube | Section 3/4-style academic speech, range of accents |
| Vocabulary | Academic Word List (Coxhead), Oxford Collocations Dictionary | High-frequency academic words and natural collocations |
| Speaking | Record yourself daily. Shadow podcast hosts | Fluency and pronunciation |

## Using these with this repo
- Track your official test scores in the same app/artifact as this repo's items (add them as custom entries).
- After each official test, add new vocabulary to a personal `words.json` in the same format as `07_vocabulary`.
