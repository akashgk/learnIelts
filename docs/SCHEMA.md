# Data schema

Everything an app needs is reachable from **`index.json`** at the repo root. It is generated by `python3 scripts/build_index.py`, so never edit it by hand.

## `index.json`

```jsonc
{
  "name": "learnIelts — IELTS Academic practice",
  "schema_version": 1,
  "commit": "42aa735",                // short SHA when the index was built
  "question_types": { "tfng": "True / False / Not Given", ... },
  "sections": [
    { "key": "reading", "label": "Reading", "path": "02_reading", "readme": "02_reading/README.md", "count": 8 }
  ],
  "items": [ /* one per exercise folder — see below */ ],
  "totals": { "items": 87, "objective_questions": 349 }
}
```

## `questions.json` (auto-gradable items)

```jsonc
{
  "total": 13,
  "instructions": "optional intro text",
  "groups": [
    {
      "type": "tfng",                 // tfng | ynng | mcq | mcq_multi | gap | matching | short
      "range": "7–10",
      "instructions": "Do the following statements agree…",
      "strategy": "optional tip shown with the solution",
      "options": [ {"key": "i", "text": "…"} ],   // group-level options (matching, mcq_multi, word boxes)
      "questions": [
        {
          "n": 7,                     // number, or [21, 22] for a choose-TWO item
          "prompt": "Statement / question / sentence with ________ gap",
          "options": [ {"key": "A", "text": "…"} ],  // per-question options (mcq)
          "answer": "FALSE",          // string, or array of accepted alternatives
          "explanation": "Why — with paragraph reference",
          "evidence": "optional quote from passage/transcript",
          "trap": "optional: the distractor and why it's wrong"
        }
      ]
    }
  ]
}
```

### Grading rules
1. Normalise: trim, collapse spaces, case-insensitive. You can also ignore a trailing full stop.
2. `answer` is a **string** → must equal it. An **array** → any element is accepted.
3. `mcq_multi` (`n` is an array, `answer` is an array of letters): one mark per correct letter, in any order. Each letter can count only once.
4. A single item's score scales to a /40 estimate with `raw / question_count * 40`. Look up the band in `00_exam_guide/02_band_scores/band_table.json`.

## `transcript.md` (listening)
- Speaker lines: `**SPEAKER:** text`. Regex: `^\*\*([A-Z ]+):\*\*\s+(.*)$`
- Question markers inside lines: `**[Q7]**` or `**[Q21–22]**`. Strip these before speaking.
- `meta.json.speakers` maps speaker → voice gender for `speechSynthesis`.

## `data.json` (writing task 1 visuals)

| `chart` | Shape |
|---|---|
| `line`, `bar` | `{title, unit, x: [...], series: [{name, values: [...]}]}` |
| `pie` | `{title, unit, charts: [{title, slices: [{label, value}]}]}` |
| `table` | `{title, columns: [...], rows: [[...]]}` |
| `process` | `{title, cyclic, steps: [{label, text}], branches?: [{label, text}]}` |
| `map` | `{title, maps: [{title, features: [{name, position}]}]}` |
| `mixed` | `{title, parts: [<line/bar spec>, ...]}` |

## `words.json` (vocabulary)
```json
[{"word": "mitigate", "pos": "v", "meaning": "…", "example": "…", "collocations": ["mitigate the impact"]}]
```

## `model_answer.md`
The model text comes first. Notes follow after a line containing only `---`. Split on the first `---` to show "model only" and "analysis" in separate tabs.
