## Questions 1–8 · Multiple choice (one answer)

**1. B** — Second conditional: if + past, would.

**2. B** — First conditional: if + present, will.

**3. B** — Third conditional: if + past perfect.

**4. A** — 'unless' = if not.

**5. B** — Formal second conditional uses 'were' for all persons.

**6. A** — Inversion: 'Were the government to…' = If the government were to…

**7. B** — 'provided that' = only if.

**8. A** — Zero conditional, scientific fact; passive.
