# Conditionals for Arguments — Questions

## Questions 1–8

*Choose the correct letter, A, B or C.*

**1.** If governments ____ public transport, fewer people would drive.

- **A** improve
- **B** improved
- **C** will improve

**2.** If the city builds more bike lanes, cycling ____ increase.

- **A** would
- **B** will
- **C** had

**3.** If I ____ harder, I would have passed the exam.

- **A** studied
- **B** had studied
- **C** have studied

**4.** Pollution will continue to rise ____ action is taken.

- **A** unless
- **B** if
- **C** provided

**5.** If public transport ____ free, more people would use it.

- **A** is
- **B** were
- **C** will be

**6.** ____ the government to raise taxes, people would spend less. (formal inversion)

- **A** Were
- **B** Was
- **C** If

**7.** You can join the course ____ you have a B2 level.

- **A** unless
- **B** provided that
- **C** otherwise

**8.** If water ____ to 100°C, it boils.

- **A** is heated
- **B** would be heated
- **C** will heat
