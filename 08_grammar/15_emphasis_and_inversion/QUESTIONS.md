# Emphasis: Cleft Sentences & Inversion — Questions

## Questions 1–10

*Choose the correct letter, A, B or C.*

**1.** Not only ____ technology save time, but it also reduces costs.

- **A** does
- **B** is
- **C** do

**2.** ____ worries many parents is screen time.

- **A** That
- **B** What
- **C** Which

**3.** It is the government ____ should take action.

- **A** that
- **B** what
- **C** where

**4.** Rarely ____ such a dramatic increase.

- **A** we have seen
- **B** have we seen
- **C** we saw

**5.** Only by working together ____ solve this problem.

- **A** we can
- **B** can we
- **C** we could

**6.** Never before ____ so many people lived in cities.

- **A** have
- **B** has
- **C** did

**7.** Which sentence is a correct cleft sentence?

- **A** What we need is more investment.
- **B** What we need it is more investment.
- **C** What need we is more investment.

**8.** Not only ____ the policy unpopular, but it was also expensive.

- **A** was
- **B** did
- **C** has

**9.** Which is natural formal English?

- **A** Seldom do politicians admit mistakes.
- **B** Seldom politicians do admit mistakes.
- **C** Seldom politicians admit mistakes do.

**10.** ____ is not the cost but the time that matters.

- **A** It
- **B** What
- **C** There
