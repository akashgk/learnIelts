# Grammar — Prepositions for Data & Time

*Use by, of, at, to, from, between correctly when describing numbers and trends.*

## The key data prepositions
| Pattern | Meaning | Example |
|---|---|---|
| *rise **by** 10%* | the size of the change | *Sales rose **by** 10%.* |
| *rise **to** 50%* | the new level | *Sales rose **to** 50%.* |
| *rise **from** X **to** Y* | start and end | *from 20% to 50%* |
| *a rise **of** 10%* | (noun) size of change | *There was a rise **of** 10%.* |
| *a rise **in** sales* | (noun) what changed | *a rise **in** sales* |
| *stand **at** / peak **at*** | a level | *Unemployment stood **at** 5%.* |
| *fluctuate **between** X **and** Y* | range | |

## Time prepositions
*in 2020, in the 1990s, in March* · *on Monday, on 5 May* · *at the start of / at the end of* · *by 2030* (= not later than) · *over the period / over the next decade* · *during the 1980s* · *from 2000 to 2010*
